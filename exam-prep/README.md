## 2. דף עזר: קבצים

עבודה עם קובץ היא תמיד **שלושה שלבים**: פתיחה ← פעולה (קריאה או כתיבה) ← סגירה.

| הפקודה | מה היא עושה |
|---|---|
| `file = open("data.txt", "r")` | פתיחה **לקריאה**. אם הקובץ לא קיים, יש שגיאה |
| `file = open("data.txt", "w")` | פתיחה **לכתיבה**. **מוחק** את מה שהיה בקובץ, או יוצר קובץ חדש |
| `file = open("data.txt", "a")` | פתיחה **להוספה**. כותב בסוף הקובץ, בלי למחוק |
| `file.close()` | סגירה. **חובה** בסוף, כדי שהשינויים יישמרו |
| `file.read()` | כל הקובץ כ**מחרוזת אחת** ארוכה |
| `file.readline()` | **שורה אחת**. כל קריאה נוספת מחזירה את השורה הבאה |
| `file.readlines()` או `list(file)` | **רשימה** של כל השורות. כל שורה עם `\n` בסופה |
| `for line in file:` | מעבר על השורות אחת אחרי השנייה |
| `file.write(text)` | כותב **מחרוזת** (רק במצב `"w"` או `"a"`). לא מוסיף ירידת שורה לבד: כותבים `"\n"` |

> ⚠️ **כל מה שנקרא מקובץ הוא מחרוזת.** כדי להשוות מספר או לחשב איתו צריך `int()` (או `float()`). בלי זה `data[2] < 56` נכשל בשגיאה.

## 3. דף עזר: מחרוזות

| הפקודה | מה היא עושה | דוגמה (`text = "apple-banana-orange"`) |
|---|---|---|
| `len(text)` | האורך, כולל רווחים | `19` |
| `text.split("-")` | מפרקת לפי המפריד ומחזירה **רשימה**. בלי מפריד, מפרקת לפי רווחים | `['apple', 'banana', 'orange']` |
| `text.strip()` | מורידה רווחים ו‑`\n` **מההתחלה ומהסוף**. חשובה מאוד בקריאה מקובץ | `"  hi\n".strip()` ← `"hi"` |
| `text.upper()` / `text.lower()` | אותיות גדולות / קטנות (באנגלית) | `"APPLE-BANANA-ORANGE"` |
| `text.replace(old, new)` | מחליפה כל `old` ב‑`new` | `text.replace("-", " ")` |
| `text.find(sub)` | המקום שבו `sub` **מתחיל**, או **‎-1** אם הוא לא נמצא | `text.find("banana")` ← `6` |
| `text[0]` / `text[-1]` | התו הראשון / האחרון | `"a"` / `"e"` |
| `text[1:4]` | חיתוך: מהמקום 1 עד המקום 4, **לא כולל** 4 | `"ppl"` |

## 4. הדוגמה שבהנחיות, צעד אחרי צעד

**המשימה:** בקובץ `grades.txt` כל שורה היא `שם#מקצוע#ציון`:

</div>

```text
דני#מתמטיקה#95
דנה#אנגלית#82
רון#מתמטיקה#45
שירה#היסטוריה#88
```

<div dir="rtl">

הדפיסו רק את השמות של מי שנכשל **במתמטיקה**.

</div>

```python
# 1. open the file for reading
file = open("grades.txt", "r")

# 2. all the lines of the file, as a list
lines = list(file)

# 3. go over the lines one by one
for line in lines:
    # split the line by "#" into a list of 3 items
    data = line.split("#")
    name = data[0]          # index 0: the name
    subject = data[1]       # index 1: the subject
    grade = int(data[2])    # index 2: the grade, as an int, so it can be compared

    # 4. the subject is math and the grade is a fail
    if subject == "מתמטיקה" and grade < 55:
        print(name)

# 5. close the file
file.close()
```

<div dir="rtl">

**שלוש נקודות שהבחינה בודקת:**
1. **מצב הפתיחה:** קריאה היא `"r"`, ובסוף תמיד `close()`.
2. **`split("#")`** יוצר בכל סיבוב רשימה `data`: במקום 0 השם, במקום 1 המקצוע, ובמקום 2 הציון.
3. **המרת טיפוס:** הציון מגיע מהקובץ כטקסט, ולכן `int(data[2])`. (`int` מתעלם מה‑`\n` שבסוף השורה. אם השדה **האחרון** היה טקסט, היה צריך `line.strip()` לפני ה‑`split`.)

> 📝 **הערה למורים:** במסמך ההנחיות המשימה אומרת "ציון נמוך מ‑56", אבל בקוד הפתרון שם כתוב `grade < 55`. ציון עובר הוא 55, ולכן כאן כתבנו `grade < 55`. כדאי לשים לב לניסוח המדויק של כל שאלה בבחינה.
